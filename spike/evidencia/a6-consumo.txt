## Genie: pregunta
¿Cuántas entidades distintas (LEI) hay en la tabla gleif_iceberg y cuáles son las 3 primeras por nombre legal?
estado: COMPLETED
SQL generado: WITH ranked_entities AS (SELECT `lei`, `nombre_legal`, RANK() OVER (ORDER BY `nombre_legal` ASC) AS rnk FROM `entity360_ext`.`spike`.`gleif_iceberg` WHERE `lei` IS NOT NULL AND `nombre_legal` IS NOT NULL) SELECT 'entidades_distintas' AS tipo, COUNT(DISTINCT `lei`) AS valor, NULL AS lei, NULL AS nombre_legal FROM `entity360_ext`.`spike`.`gleif_iceberg` WHERE `lei` IS NOT NULL UNION ALL SELECT 'top_3_por_nombre_legal' AS tipo, NULL AS valor, `lei`, `nombre_legal` FROM ranked_entities WHERE rnk <= 3;
